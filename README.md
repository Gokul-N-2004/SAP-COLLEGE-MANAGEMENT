This is the SAP College Management task developed for learning and practicing GitHub branch configuration.



# Faculty Module

### SAP RAP Managed Scenario 

The Faculty Module is developed using SAP RAP Managed Scenario.

### Module Includes

- Faculty ID
- Faculty Name
- Faculty Subject
- Faculty Salary
- Faculty Mobile Number
- Faculty Email
- Faculty Age
- Faculty Experience
